## ⭐ Spotlight: Pipesets AI

<div align="center">

**[Pipesets AI](https://github.com/wshamim1/pipesets-ai)**: build, test and ship LLM agent pipelines in one self-hosted platform.

<a href="https://github.com/wshamim1/pipesets-ai">
  <img src="https://raw.githubusercontent.com/wshamim1/pipesets-ai/main/docs/media/pipesets-tour.webp" width="820" alt="A short tour of Pipesets AI: the Apps hub, a multi-agent pipeline on the Build canvas, evals, Monitor, Automation, Settings and the desktop app" />
</a>

</div>

Design a pipeline on a visual canvas (models, tools, memory, retrieval, guardrails, multi-agent orchestration),
test it against eval datasets, publish a version, and run it from the UI, on a schedule, from a webhook, through
a versioned REST API, from any MCP client, or as a shareable chat link.

| | |
|---|---|
| 🧠 **19 model providers / 73 models** through its own LLM gateway, local models included (Ollama, llama.cpp) | 🧰 **209 built-in tools** and **110 MCP servers**, plus custom Python tools in a container sandbox |
| 🧪 **Evals built in**: datasets, scorers, synthetic test cases, eval-gated publishing | 🔐 **Team-ready**: multi-tenant access control, encrypted secrets vault, guardrails, budgets, audit log |
| 🚢 **Runs anywhere**: one script locally, Docker / Podman Compose, Kubernetes, or a desktop app | 🔓 **No lock-in**: export to LangChain, CrewAI, AutoGen, notebooks or Docker |
